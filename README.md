# Melatonin Vintner Experience

MELATONIN VINTNER — PREMIUM WINE BRAND WEBSITE



You are a senior creative director, premium brand designer, UI/UX designer, and elite full-stack frontend engineer.



Your task is to design and build a production-ready premium website for a wine brand called:



🍷 MELATONIN VINTNER



Melatonin Vintner is a premium wine business offering a curated selection of wines across different varieties, styles, and regions.



The goal is to create a website that feels like a high-end wine house, not a generic wine store template.



The final experience should communicate:



Luxury · Elegance · Sophistication · Heritage · Exclusivity · Quality



⸻



1. CORE OBJECTIVE



Build a visually exceptional, modern wine website that immediately establishes Melatonin Vintner as a premium wine brand.



When a visitor lands on the website, the first impression should feel comparable to a high-end:



Wine estate

Luxury beverage brand

Boutique winery

Premium hospitality brand

High-end lifestyle company



The website should feel expensive, intentional, refined, and editorial.



Avoid the appearance of:



Generic ecommerce templates

Cheap wine shops

Overly colorful beverage websites

Basic WordPress-style layouts

Template-generated AI websites

Excessive animations

Cluttered product grids



⸻



2. BRAND DIRECTION



The visual identity should revolve around a sophisticated wine aesthetic.



Suggested design language



Primary mood:



Dark · Elegant · Warm · Minimal · Cinematic



Use a sophisticated palette such as:



Deep burgundy / wine

Near-black

Warm ivory

Champagne/gold accents

Muted earthy tones



Do not overuse gold.



Gold should be used as a subtle luxury accent, not as the dominant color.



Typography should combine:



Display typography



Elegant high-contrast serif typography for:



Headlines

Product names

Brand statements

Editorial sections



Supporting typography



Clean modern sans-serif typography for:



Navigation

Descriptions

Prices

Buttons

Product details



The combination should feel similar to luxury fashion/editorial branding, while remaining distinctly wine-focused.



⸻



3. HERO SECTION

The hero should feature:



MELATONIN VINTNER

Hero visual

Elegant wine bottle photography

Vineyard atmosphere

Sophisticated composition



The hero should feel editorial and cinematic, not like a stock ecommerce banner.

16. AGE VERIFICATION

The implementation should be professional and consistent with the brand.



Do not claim a specific legal age universally; requirements vary by jurisdiction.

The final website should look like something that could realistically represent a premium international wine brand.

Minimal without being empty.

Premium without being pretentious.

Modern without losing the heritage of wine.

IMPLEMENTATION RULE



Before writing code:



Audit the existing project/environment.

Understand the available assets and technical stack.

Establish the visual direction.

Build the core design system.

Build the homepage.

Build the collection/product experience.

Build supporting sections/pages.

Implement responsive behavior.

Add interactions and animations.

Perform accessibility, SEO, performance, and responsive QA.



Do not settle for placeholders where a polished implementation is possible.



Do not create a generic wine template.



The final result should feel like a real premium brand website ready for launch.
